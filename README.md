# Reel Processor

Обработка вертикальных роликов одним перетаскиванием: приведение к 1080×1920, лёгкая зернистость и коррекция, перекодирование в H.264/AAC и полная зачистка метаданных.

## Что делает

```
scale=1080:1920 (с паддингом) → noise=alls=1.5 → eq (brightness/contrast/saturation) → unsharp
libx264 CRF 20, preset medium, High@4.1 · AAC 160k 44.1 kHz · +faststart · bitexact · метаданные вычищены
```

Результат кладётся рядом с исходником под именем `имя_processed.mp4`.

## Запуск (Windows)

1. Положить `ffmpeg.exe` в папку с файлами (сборки: https://www.gyan.dev/ffmpeg/builds/)
2. Запустить `Reel Processor.bat`
3. Перетащить ролики в окно (или нажать «Выбрать файлы»)

Окно на PowerShell + WinForms, ничего устанавливать не нужно. `gui.ps1` должен лежать рядом с `.bat`.

## Раздача

Заархивировать папку вместе с бинарником ffmpeg — у получателя ничего не устанавливается.
